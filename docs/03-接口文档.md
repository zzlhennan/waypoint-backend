# 第一部分：概要设计（HLD）

## 1. 系统架构

单体 Spring Boot 应用，经典分层。无前端、无用户系统，唯一对外接口 `GET /along`。

```
调用方(Postman/浏览器)
        │  GET /along
        ▼
  controller        AlongController        # 接收参数、校验、返回 VO
        ▼
  service           AlongService(+impl)    # 编排：定位→路线→采样→POI→排序
        ▼
  feignclient       AmapClient(Feign)      # 唯一出口：调高德 API
        ▼
  高德开放平台       place/text · driving · around

  支撑：config(配置) · utils(DetourCalculator) · exception(异常) · constant(常量)
        dto(内部对象) · vo(返回对象) · mapper(留空)
```

## 2. 技术栈

JDK 21 · Spring Boot 4.1.2（保持勿降）· Maven · H2（文件模式，MVP 留空）· Feign(OpenFeign，配 Spring Cloud 2025.1.x Oakwood) · 高德 API
包名 `com.zzl.waypointbackend`

## 3. 模块划分（包职责）

| 包 | 职责 | 关键类 |
|---|---|---|
| `config` | 配置读取 | AmapProperties、AlongProperties |
| `constant` | 常量 | 高德端点、错误码、业务常量 |
| `controller` | 接口层 | AlongController |
| `service`/`impl` | 业务编排 | AlongService / AlongServiceImpl |
| `feignclient` | 外部调用 | AmapClient（Feign 声明式） |
| `mapper` | 数据访问 | MVP 留空 |
| `dto` | 内部/算法对象 | Point、PoiCandidate、AlongQuery |
| `vo` | 返回对象 | AlongResponse、PoiItem |
| `exception` | 异常处理 | BizException、GlobalExceptionHandler |
| `utils` | 工具 | DetourCalculator |

## 4. 核心业务流程

```
入参 city, start, end, keyword (+可选 mode/topN/radius/types/strategy)
   │
   ① place/text 定位起点终点（取 pois[0].location）
   ② 路线规划（按 mode 选 driving/walking/bicycling）→ 路径坐标串 List<Point>
   ③ 沿路径每 500m 采样
   ④ 每采样点：radius(默认500m) 搜 POI，无结果扩到 1km 重试一次
   ⑤ 候选 POI 算到主路折线的最近直线距离（欧氏）
   ⑥ 硬过滤：POI 离主路 > 1km 丢弃（兜底）
   ⑦ 升序排序取 Top N；为空 → 404
```

## 5. 外部依赖

高德开放平台 3 个接口（定位 / 路线 / 周边），**详见 `docs/02-高德API.md`**。

## 6. 接口清单

| 接口 | 方法 | 说明 |
|---|---|---|
| `/along` | GET | 沿途 POI 推荐（MVP 唯一接口） |

# 第二部分：详细设计（LLD）

## 7. 接口详细定义：GET /along

### 7.1 请求参数

**必填**：
| 参数 | 说明 | 示例 |
|---|---|---|
| `city` | 城市名，定位消歧 | `北京` |
| `start` | 起点地名 | `奥森公园` |
| `end` | 终点地名 | `望京SOHO` |
| `keyword` | 需求关键词 | `咖啡` |

**可选**（均有默认值，不填即极简用法）：
| 参数 | 默认 | 说明 | 高德能力映射 |
|---|---|---|---|
| `mode` | `driving` | 交通方式：`driving`/`walking`/`bicycling` | 路径规划接口（骑行用 2.0） |
| `topN` | `3` | 返回数量上限（1–10） | 本地截取 |
| `radius` | `500` | 采样点搜索半径(米)，500–2000 | place/around `radius` |
| `types` | 空 | POI 类型编码过滤（如餐饮 `050000`） | place/around `types` |
| `strategy` | `0` | 驾车算路策略(仅 driving)：0速度/1费用/2距离/3不走高速 | direction `strategy` |

> 实现优先级：`mode`/`topN`/`radius` 零成本，MVP 实现；`types`/`strategy` 第二步。

### 7.2 请求示例

```
# 极简（全默认）
GET /along?city=北京&start=奥森公园&end=望京SOHO&keyword=咖啡

# 骑行 + 返回5家 + 限定餐饮
GET /along?city=北京&start=奥森公园&end=望京SOHO&keyword=咖啡&mode=bicycling&topN=5&types=050000
```

### 7.3 成功响应（200）

```json
{
  "query": { "city": "北京", "start": "奥森公园", "end": "望京SOHO", "keyword": "咖啡", "mode": "bicycling" },
  "result": [
    {
      "name": "%咖啡店铺名",
      "address": "%地址",
      "distanceToRouteMeters": 200,
      "location": "116.4635,39.9965",
      "tel": "010-xxxxxxx",
      "type": "餐饮服务;咖啡厅",
      "adname": "朝阳区"
    }
  ]
}
```

### 7.4 错误响应

| HTTP | 触发条件 | 提示 |
|---|---|---|
| 400 | 起点/终点定位失败 | "找不到起点/终点：XX" |
| 404 | 整条路线 1km 内无任何 POI | "沿途 1km 内没找到 XX" |
| 502 | 高德 API 调用失败 | "地图服务暂时不可用" |

## 8. 核心类设计

### 8.1 配置类（config）

```java
@ConfigurationProperties("amap")   // AmapProperties：key、baseUrl
@ConfigurationProperties("along")  // AlongProperties：sampleIntervalMeters、searchRadiusMeters、
                                   //   searchRadiusRetryMeters、maxDetourMeters、topN
```

### 8.2 外部调用（feignclient）

```java
@FeignClient(name = "amap", url = "${amap.base-url}")
public interface AmapClient {
    @GetMapping("/v3/place/text")        // 定位：地名 → 坐标
    AmapPoiResponse searchText(String keywords, String city, Boolean citylimit, ...);

    @GetMapping("/v3/direction/driving") // 驾车路线（walking/bicycling 类似）
    AmapRouteResponse driving(String origin, String destination, Integer strategy, ...);

    @GetMapping("/v5/place/around")      // 周边 POI
    AmapPoiResponse around(String location, String keywords, Integer radius, String types, ...);
}
```

### 8.3 距离计算（utils）

```java
public class DetourCalculator {
    // POI 到主路折线的最近直线距离（米），欧氏近似
    public static double minDistanceMeters(Point poi, List<Point> route);
    // 辅助：点到线段的最短距离
    private static double pointToSegmentMeters(Point p, Point a, Point b);
}
```

### 8.4 业务编排（service）

```java
public interface AlongService {
    AlongResponse along(AlongQuery query);   // 串起 定位→路线→采样→POI→排序→TopN
}
```

### 8.5 接口层（controller）

```java
@RestController
public class AlongController {
    @GetMapping("/along")
    public AlongResponse along(@Validated AlongQuery query);   // 参数校验 + 调用 service
}
```


## 10. 异常与错误处理

- `BizException`（exception 包）：承载业务错误码 + 提示
- `GlobalExceptionHandler`（`@RestControllerAdvice`）：统一把异常映射为 400/404/502 及统一错误响应体
- 高德返回 `status != "1"` → 包装为 BizException

|---|---|---|
| `Point` | dto | longitude、latitude |
| `PoiCandidate` | dto | name、address、location、tel、type、adname、distanceToRouteMeters |
