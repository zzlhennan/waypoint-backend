# 第一部分：概要设计（HLD）

## 1. 系统架构

单体 Spring Boot 应用，经典分层。无前端、无用户系统，唯一对外接口 `GET /along`。

```
调用方(Postman/浏览器)
        │  GET /along
        ▼
  controller        AlongController        # 接收参数、校验、返回 VO
        ▼
  service           AlongService(+impl)    # 编排：定位→路线→采样→POI→排序
        ▼
  feignclient       AmapClient(Feign)      # 唯一出口：调高德 API
        ▼
  高德开放平台       place/text · driving · around

  支撑：config(配置) · utils(DetourCalculator) · exception(异常) · constant(常量)
        dto(内部对象) · vo(返回对象) · mapper(留空)
```

## 2. 技术栈

JDK 21 · Spring Boot 4.1.2（保持勿降）· Maven · H2（文件模式，MVP 留空）· Feign(OpenFeign，配 Spring Cloud 2025.1.x Oakwood) · 高德 API
包名 `com.zzl.waypointbackend`

| 包 | 职责 | 关键类 |

## 4. 核心业务流程

```
入参 city, start, end, keyword (+可选 mode/topN/radius/types/strategy)
   │
   ① v5 place/text 定位起点终点（region+city_limit，取 pois[0].location）
   ② v5 路线规划（按 mode，传 show_fields=polyline）→ 路径坐标串 List<Point>
   ③ 沿路径每 500m 采样（折线累计 + 段内插值）
   ④ 每采样点：radius(默认500m) 搜 POI，无结果扩到 1km 重试一次
   ④.5 合并候选 POI，按 id 去重（相邻采样圈重叠，同店会重复）
   ⑤ 对去重后 POI 算 distanceToRouteMeters（到折线最近距离，欧氏近似含经纬度→米换算）
   ⑥ 硬过滤：POI 离主路 > 1km 丢弃（兜底）
   ⑦ 按 distanceToRouteMeters 升序取 Top N；为空 → 404
```

## 5. 外部依赖

高德开放平台 3 个接口（定位 / 路线 / 周边），**详见 `docs/02-高德API.md`**。

# 第二部分：详细设计（LLD）

## 7. 接口详细定义：GET /along

### 7.1 请求参数

**必填**：
| 参数 | 说明 | 示例 |
|---|---|---|
| `city` | 城市名，定位消歧 | `北京` |
| `start` | 起点地名 | `奥森公园` |
| `end` | 终点地名 | `望京SOHO` |
| `keyword` | 需求关键词 | `咖啡` |

**可选**（均有默认值，不填即极简用法）：
| 参数 | 默认 | 说明 | 高德能力映射 |
|---|---|---|---|
| `mode` | `driving` | 交通方式：`driving`/`walking`/`bicycling` | 路径规划接口（骑行用 2.0） |
| `topN` | `3` | 返回数量上限（1–10） | 本地截取 |
| `radius` | `500` | 采样点搜索半径(米)，500–2000 | place/around `radius` |
| `types` | 空 | POI 类型编码过滤（如餐饮 `050000`） | place/around `types` |
| `strategy` | `0` | 驾车算路策略(仅 driving)：0速度/1费用/2距离/3不走高速 | direction `strategy` |

> 实现优先级：`mode`/`topN`/`radius` 零成本，MVP 实现；`types`/`strategy` 第二步。

### 7.2 请求示例

```
# 极简（全默认）
GET /along?city=北京&start=奥森公园&end=望京SOHO&keyword=咖啡

# 骑行 + 返回5家 + 限定餐饮
GET /along?city=北京&start=奥森公园&end=望京SOHO&keyword=咖啡&mode=bicycling&topN=5&types=050000
```

### 7.3 成功响应（200）

```json
{
  "query": { "city": "北京", "start": "奥森公园", "end": "望京SOHO", "keyword": "咖啡", "mode": "bicycling" },
  "result": [
    {
      "name": "%咖啡店铺名",
      "address": "%地址",
      "distanceToRouteMeters": 200,
      "location": "116.4635,39.9965",
      "tel": "010-xxxxxxx",
      "type": "餐饮服务;咖啡厅",
      "adname": "朝阳区"
    }
  ]
}
```

### 7.4 错误响应

| HTTP | 触发条件 | 提示 |
|---|---|---|
| 400 | 起点/终点定位失败 | "找不到起点/终点：XX" |
| 404 | 整条路线 1km 内无任何 POI | "沿途 1km 内没找到 XX" |
| 502 | 高德 API 调用失败 | "地图服务暂时不可用" |

## 8. 核心类设计

### 8.1 配置类（config）

```java
@ConfigurationProperties("amap")   // AmapProperties：key、baseUrl
@ConfigurationProperties("along")  // AlongProperties：sampleIntervalMeters、searchRadiusMeters、
                                   //   searchRadiusRetryMeters、maxDetourMeters、topN
```

### 8.2 外部调用（feignclient）

```java
@FeignClient(name = "amap", url = "${amap.base-url}")
public interface AmapClient {

    // ── 搜索 2.0（v5）：定位 + 周边共用同一响应结构 AmapV5PoiResponse ──
    @GetMapping("/v5/place/text")           // 定位：地名 → 坐标（取 pois[0].location）
    AmapV5PoiResponse searchText(String keywords, String region, Boolean cityLimit, String showFields, ...);  // 城市入参 region/cityLimit（v5，≠v3 city/citylimit）

    @GetMapping("/v5/place/around")         // 周边 POI（tel 等需 show_fields=business）
    AmapV5PoiResponse around(String location, String keywords, Integer radius,
                             String types, String showFields, ...);

    // ── 路径规划 2.0（v5）：driving/walking/bicycling 共用 AmapV5RouteResponse ──
    // ⚠️ 必须传 showFields="polyline"，否则 steps 不返回坐标串（默认只有 instruction/orientation/step_distance）
    @GetMapping("/v5/direction/driving")    // 驾车（mode=driving）
    AmapV5RouteResponse driving(String origin, String destination, Integer strategy, String showFields, ...);

    @GetMapping("/v5/direction/walking")    // 步行（mode=walking）
    AmapV5RouteResponse walking(String origin, String destination, String showFields, ...);

    @GetMapping("/v5/direction/bicycling")  // 骑行（mode=bicycling）
    AmapV5RouteResponse bicycling(String origin, String destination, String showFields, ...);
}
```

> ✅ **全 v5 统一（方案B）**：全站只用 v5 2.0，**只需 2 个响应 DTO**：
> - **搜索** `AmapV5PoiResponse`：`place/text`（定位）与 `place/around`（周边）**共用**，结构一致（实测确认）。
> - **路径** `AmapV5RouteResponse`：`driving`/`walking`/`bicycling` **共用**，取 `paths[0].steps[].polyline` 坐标串（**必须传 `show_fields=polyline`**，默认无坐标串，已实测确认）。polyline 按 `;` 分点、`,` 分经纬度。
> - 定位：`pois[0].location` 即坐标（v5 place/text 实测"奥森公园"定位正常）。
> - 要 `tel` 时：`around`/`searchText` 传 `show_fields=business`，取 `poi.business.tel`（嵌套子对象）。

### 8.3 距离计算（utils）

```java
public class DetourCalculator {
    // 沿折线每 interval 米采样一个点（累计长度 + 段内插值）
    public static List<Point> sampleRoute(List<Point> route, int intervalMeters);
    // POI 到主路折线的最近直线距离（米）= distanceToRouteMeters
    public static double minDistanceMeters(Point poi, List<Point> route);

    // 经纬度→米换算（欧氏近似的前提，勿直接拿经纬度差当米）：
    //   dx = (lon1-lon2) * 111000 * cos(平均纬度)   // 经度随纬度缩放
    //   dy = (lat1-lat2) * 111000                    // 纬度固定
    //   距离 = sqrt(dx*dx + dy*dy)
    private static double pointToSegmentMeters(Point p, Point a, Point b);
}
```

## 10. 异常与错误处理

- `BizException`（exception 包）：承载业务错误码 + 提示
- `GlobalExceptionHandler`（`@RestControllerAdvice`）：统一把异常映射为 400/404/502 及统一错误响应体
- 高德返回 `status != "1"` → 包装为 BizException

## 11. 数据对象

| 对象 | 包 | 关键字段 |
|---|---|---|
| `Point` | dto | longitude、latitude |
| `PoiCandidate` | dto | name、address、location、tel、type、adname、distanceToRouteMeters |
| `AlongQuery` | dto | city、start、end、keyword、mode、topN、radius、types、strategy |
| `AlongResponse` | vo | query、result: List<PoiItem> |
| `PoiItem` | vo | name、address、distanceToRouteMeters、location、tel、type、adname |

**高德响应 DTO（feignclient 层，仅 2 个）**：
| 对象 | 覆盖接口 | 说明 |
|---|---|---|
| `AmapV5PoiResponse` | `place/text` + `place/around` | 搜索 2.0 响应：`status`/`info`/`infocode` + `pois[]`；POI 含 `business` 子对象（`show_fields=business` 时） |
| `AmapV5RouteResponse` | `driving`/`walking`/`bicycling` | 路径 2.0 响应：`route.paths[].steps[].polyline` 坐标串（需 `show_fields=polyline`，已实测）；polyline 按 `;` 分点、`,` 分经纬度 |

> ⚠️ **两个 distance 别混**：高德 around 返回的 `poi.distance` = POI→**采样点**（我们**不用**）；响应里的 `distanceToRouteMeters` = POI→**整条折线**（DetourCalculator 自算）。候选 POI 需按 `id` 去重后再算距离。
