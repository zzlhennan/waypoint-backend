# 前端页面设计（v1.0 · HTML 单文件）

> 本文档是 `docs/01-需求文档.md` 的**详细设计补充**——不新增需求，只把"用 Postman 调接口"变成"用浏览器调接口"。
> 产品定位、成功标准、算法口径以 01 为准，本文档只管页面长什么样、怎么交互、调哪些接口。
> 未来 Flutter 移动端设计另起 06 文档，本文档的布局结构/字段名/接口契约作为 Flutter 复用依据。

## 1. 目标与范围

### 1.1 目标

- 让开发者本人**每天骑车通勤时真的用起来**（PRD 成功标准：连续用 5 天）
- 一个 HTML 文件，放进 `src/main/resources/static/`，访问 `http://localhost:22830/` 即用
- 零构建、零 npm、零框架（原生 HTML + CSS + JS）
- 为未来 Flutter 移动端铺路（接口契约、字段名、布局结构复用）

### 1.2 不在本期范围

- 不做用户登录/注册
- 不做收藏/评分/评论
- 不做地图嵌入（只给"打开高德地图"链接）
- 不做后端改动（除了新增 `GET /category/list?dictType=poi_category`）
- 不做 PWA manifest（等真用一阵子再加）

### 2.1 布局原则（为 Flutter 铺路）

| 区块 | HTML 实现 | Flutter 对应 |
|---|---|---|
| 输入区竖排 | `<div>` + `<label>` + `<input>` | `Column` + `TextField` |
| 分类 tab 横排 | `<button>` 横排 | `Row` + `ChoiceChip` |
| mode radio | `<input type="radio">` | `RadioListTile` |
| 结果列表 | `<div>` 循环渲染 | `ListView.builder` |

**关键约束**：
- 不写复杂 CSS 框架（不用 Tailwind/Bootstrap）
- 不写花哨动画/渐变/毛玻璃
- 朴素布局，Flutter 照着画结构即可

## 3. 交互流程

### 3.1 首次使用

1. 打开页面 → localStorage 为空 → 输入框占位提示"例如：北京 / 奥森公园 / 望京SOHO / 咖啡"
2. 用户填好 4 个输入框 + 选分类（默认"全部"）+ 选方式（默认骑行）
3. 点"开始搜索" → 按钮置灰 + 显示 loading
4. fetch `/along/search?...` → 渲染结果列表
5. 输入内容自动写入 localStorage（下次打开自动填充）

### 3.2 日常使用（通勤场景）

1. 打开页面 → localStorage 已记住"北京 / 奥森公园 / 望京SOHO / 咖啡"
2. 一键点"开始搜索"
3. 结果出来，挑一家顺路的

### 3.3 切换分类 tab

1. 用户点"咖啡厅"tab
2. 当前 tab 高亮，其他 tab 恢复
3. **自动重新请求** `/along/search?category=咖啡厅&...其他参数不变`
4. 结果列表刷新

### 3.4 错误场景

| HTTP | 页面表现 |
|---|---|
| 400 | 结果区显示："❌ {message}"（如"找不到起点：xxx"） |
| 404 | 结果区显示："🔍 {message}"（如"沿途 1km 内没找到 咖啡"） |
| 502 | 结果区显示："⚠️ {message}"（如"地图服务暂时不可用"） |
| 网络断开 | fetch 抛异常 → 结果区显示"网络不通，检查一下？" |

**关键**：错误文案**直接用后端返回的 `message` 字段**，前端不自己写错误文案（未来 Flutter 复用同一套文案）。

## 4. 接口依赖

### 4.1 现有接口（不改）

#### `GET /along/search`

**请求参数**：
| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `city` | ✅ | — | 城市名 |
| `start` | ✅ | — | 起点地名 |
| `end` | ✅ | — | 终点地名 |
| `keyword` | ✅ | — | 关键词 |
| `mode` | ❌ | `driving` | `driving`/`walking`/`bicycling` |
| `topN` | ❌ | `3` | 返回数量 |
| `radius` | ❌ | `500` | 搜索半径 |
| `category` | ❌ | 空 | 分类名（如"咖啡厅"），后端 DictUtils 翻译 |
| `strategy` | ❌ | `0` | 仅 driving 生效 |

**成功响应（200）**：
```json
{
  "query": { "city": "北京", "start": "奥森公园", "end": "望京SOHO", "keyword": "咖啡", "mode": "bicycling" },
  "result": [
    {
      "name": "星巴克(北京望京SOHO T3店)",
      "address": "望京街10号望京SOHO T3F1层",
      "distanceToRouteMeters": 12,
      "location": "116.480893,39.995884",
      "tel": "4008206998",
      "type": "餐饮服务;咖啡厅;星巴克咖啡",
      "adname": "朝阳区"
    }
  ]
}
```

**错误响应（非 200）**：
```json
{ "code": 400, "message": "找不到起点：xxx" }
```

### 4.2 新增接口（后端补）

#### `GET /category/list?dictType=poi_category`

**用途**：返回分类 tab 列表，前端拿来渲染横排按钮。

**响应**：
```json
{
  "categories": [
    { "label": "全部" },
    { "label": "咖啡厅" },
    { "label": "冷饮" },
    { "label": "糕饼" },
    { "label": "甜品" },
    { "label": "茶艺" },
    { "label": "加油站" },
    { "label": "便利店" }
  ]
}
```

**实现要点**（给后端）：
- 直接复用 `DictUtils.getDictList(TYPE_POI_CATEGORY)`
- "全部"由后端拼在列表第一项（types=null 表示不过滤，是前端概念，不算在 DictUtils 里）
- **只返回 label，不返回 types**：types 编码是后端翻译用的内部细节，不下发给前端，避免前端误传裸编码
- 前端拿到 label 后，点 tab 原样作为 `category` 参数回传，翻译仍收口在后端 DictUtils

**为什么需要这个接口**：
- 现在 HTML 调一次拿列表
- 未来 Flutter 调同一个接口拿同样列表
- 后端字典加新分类，前端不用改代码

## 5. localStorage 字段（记住常用输入）

| 字段名 | 类型 | 说明 | Flutter 对应（未来） |
|---|---|---|---|
| `waypoint.city` | string | 常用城市（默认"北京"） | `SharedPreferences.getString("waypoint.city")` |
| `waypoint.start` | string | 常用起点（如"奥森公园"） | 同上 |
| `waypoint.end` | string | 常用终点（如"望京SOHO"） | 同上 |
| `waypoint.keyword` | string | 常用关键词（如"咖啡"） | 同上 |
| `waypoint.mode` | string | 默认方式（如"bicycling"） | 同上 |
| `waypoint.topN` | number | 默认返回数（如 3） | 同上 |
| `waypoint.category` | string | 当前选中分类（默认"全部"） | 同上 |

**写入时机**：每次点"开始搜索"时，把当前表单值全部写入 localStorage。

**读取时机**：页面加载时，从 localStorage 读，填充表单；读不到用占位提示。

**字段名规范**：统一加 `waypoint.` 前缀，避免和其他网站冲突。

## 6. 结果列表项渲染规则

### 6.1 距离文案（用户选定 C 方案：两者都要）

格式：`{距离米数} · {评级}`

| 距离范围 | 评级文案 | 示例 |
|---|---|---|
| 0–100 米 | `顺路` | `12 米 · 顺路` |
| 101–200 米 | `稍绕` | `150 米 · 稍绕` |
| 201–500 米 | `绕远了` | `320 米 · 绕远了` |
| > 500 米 | `太远` | `800 米 · 太远` |

**为什么这么分（开发者体感）**：
- 100 米内 = 拐一下就到，不用犹豫
- 100–200 米 = 明显偏离主路，但还能接受
- 200–500 米 = 不值得专门去
- >500 米 = 太远，排除

**未来调整**：这些阈值写在前端常量里，改文案不用动后端。

### 6.2 每条结果显示什么

| 字段 | 显示 | 交互 |
|---|---|---|
| `name` | 店名（加粗） | — |
| `distanceToRouteMeters` | `{米数} · {评级}` | — |
| `address` | 地址 | — |
| `tel` | 📞 电话号码 | **前端拼** `tel:{tel}` 链接，手机点了直接拨号 |
| `location` + `name` | 🗺️ 打开地图 | **前端拼** 高德地图链接（见下） |

> **重要**：后端返回的 JSON **没有 `telLink` / `mapLink` 字段**——链接是前端用现有字段拼出来的，后端不用改。

**"打开地图"链接格式（前端拼）**：
```
https://uri.amap.com/marker?position={location}&name={encodeURIComponent(name)}
```
其中 `location` 直接用后端返回的 `"116.480893,39.995884"` 格式。
点击后跳高德地图 App / 网页版，显示该 POI 位置。

**电话链接格式（前端拼）**：
```html
<a href="tel:{tel}">📞 {tel}</a>
```

**如果 `tel` 为空**：不显示电话那一行。

---

### 6.2.1 距离不换算成时间

**为什么**：
- `distanceToRouteMeters` 是**直线距离**（欧氏近似），不是实际步行/骑行距离
- 没有路网，不知道实际要拐几个弯、过几个马路
- 前端拿直线距离除以速度换算成时间，会误导用户（"绕路 12 米"听着像 5 秒，实际可能要 30 秒过马路）

**结论**：距离文案只显示米数 + 评级，不换算成时间。

## 7. Loading 状态

### 7.1 触发

点"开始搜索"按钮后：
- 按钮置灰（`disabled`），文案变成"搜索中..."
- 按钮下方显示一行小字："⏳ 预计 5-10 秒（后端串行调高德）"
- 结果区显示一个简单的 loading 动画（转圈 emoji 或 CSS animation）

### 7.2 结束

- fetch 返回（成功或失败）→ 按钮恢复可点
- loading 动画消失
- 结果区渲染（成功列表 / 错误提示）

### 7.3 不做的事

- 不做"已完成 3/10 个采样点"进度提示（后端要改造成本高，不值）
- 不做 WebSocket 实时进度（MVP 不需要）

## 8. 手机适配

### 8.1 viewport

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

### 8.2 布局原则

- 全宽布局，不设固定像素宽度（用百分比 / flex）
- 输入框高度 ≥ 44px（手指好点）
- 按钮高度 ≥ 44px
- 字体用系统默认（16px 基础）
- 分类 tab 可换行（8 个按钮一行放不下就换行）

### 8.3 不做的事

- 不做 iOS / Android 特殊样式差异
- 不做深色模式（先浅色）
- 不做横屏适配（竖屏够用）

## 9. 为未来 Flutter 铺路的设计约束

| 约束 | 现在 HTML 怎么做 | 未来 Flutter 怎么复用 |
|---|---|---|
| 接口契约 | `/along/search` + `/category/list?dictType=xxx` 的请求/响应字段名 | 直接抄成 Dart model 类 |
| 错误文案 | 直接显示后端 `message` | 直接显示后端 `message` |
| localStorage 字段名 | `waypoint.city` 等 | SharedPreferences 用同样 key |
| 布局结构 | 竖排输入 + 横排 tab + 列表 | Column + Row + ListView |
| 距离文案规则 | 前端常量（50/200/500 阈值） | Dart 常量照搬 |
| 分类列表来源 | 调 `/category/list?dictType=poi_category` | 调同一个接口 |

**未来 Flutter 不抄的部分**：
- HTML/CSS 样式（Flutter 自己画）
- DOM 结构
- JS 事件绑定方式
